# Varneeshwar | Portfolio

Plain HTML, CSS and JavaScript. No build step, no installs.

## Preview
Double-click `index.html`.

## Update your content
- Everything (text, skills, projects, links) lives in `data.js`. Edit it in any text editor.
- Resume: replace `assets/Varneeshwar_Resume.pdf` with your new PDF (same file name).
- Photos: replace `assets/photo-1.jpg`, `photo-2.jpg`, `photo-3.jpg` (portrait, about 720x900).
- Add a project: copy one `{ ... }` block inside `projects` in `data.js`.

## Host it free (anyone can open the link)
- **Netlify (fastest):** open app.netlify.com/drop and drag this whole folder in.
- **GitHub Pages:** create a repo, upload these files, then Settings > Pages > Deploy from branch `main` / root.
- **Cloudflare Pages or Vercel:** import the repo, no build command, output folder `/`.

Your phone number and email are public once hosted. Set them to "" in `data.js` to hide them.
